# Log analyzer App

## About

This app lets you upload your favourite log format as a text file, and an AI model analyzes your log files and generates a user-readable summary.

## Prerequisites

Before running this app, make sure you have the following pre-requisites installed.

- `uv` python package manager  (*Recommended*)
- `ollama` model provider

Install those pre-requisites into your bash terminal

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
curl -fsSL https://ollama.com/install.sh | sh
```

**Note:** Restart your shell after running these commands.

## Running the App

**Step - 1:** Navigate to the app directory and run the following command to install required python packages

```bash
uv sync
```
